Replication Materials
------

Code and data for all my published studies are available on the [Open Science Framework](https://osf.io/b3ugm/). Adhering to the idea of transparent and replicable research, I upload the materials of every published study. Feel free to use anything for secondary analyses, teaching, or other purposes.

Course Materials
------

Full courses and workshops in R and Python — multilevel modelling, panel regression, computational social science, and topic modelling — are openly available at [Czymara Courses](https://github.com/czymaraclass). See the [teaching page](/teaching/) for descriptions of the individual courses.

Code Nerd
------

If you're ever running into problems related to quantitative data analysis, I created [Code Nerd](https://chatgpt.com/g/g-J5futwiVV-code-nerd) -- a custom GPT dedicated to resolving programming queries in data wrangling and analysis. No chatter, just code 😎 Its default is R, but it can also tackle questions on Python, Stata, or any other language.

Access requires a ChatGPT account on a paid plan.

Code Nerd was featured on [InfoWorld](https://www.infoworld.com/article/3848270/genai-tools-for-r-new-tools-to-make-r-programming-easier.html).
